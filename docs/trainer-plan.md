## Diet type and rules

**Type:** high-carb maintenance then lean bulk. Burritos / bowls are the center. Not a cut. Not keto.

### Macros

| Phase | kcal/day | Protein | Carbs | Fat | Duration |
|---|---|---|---|---|---|
| **Fase 1 — mantenimiento** | 2100–2200 (**obj. 2150**; example day **2128**) | **110 g** (440 kcal, ~21%) | 250–270 g (**obj. 260**) | 65–75 g (**obj. 72**) | ~2 weeks until weight stable ~62.5–63 kg |
| **Fase 2 — lean bulk** | 2350–2500 (**obj. 2420–2440**) | **110 g** (same) | 300–330 g (**obj. 320**) | 75–85 g (**obj. 80**) | 8–16 weeks |

Fase 2 add-ons (same protein): +150 g cooked rice (~195 kcal), +1 tortilla 60 g (~185), +10–12 g AOVE (~100), +1 toast (~80), +150 g cooked potato (~116).

If a template day is **>100 kcal** off target, adjust rice / AOVE / fruit — **do not** add a shake or yogurt to “fix” it.

### Hard constraints

- **No fish except tuna**
- **No oats**
- **No daily protein shakes** (powder OK inside a recipe occasionally; grocery list blocks buying shake products)
- **Eggs are not a staple** (breakfast burrito = chicken/turkey, not eggs; rare eggs OK)
- Yogurt: **Targets + HOW-TO say OK in moderation**; Maintenance week + grocery “NO COMPRAR” say **no yogurt**. OpenGym should treat yogurt as **optional/rare**, not a default food.
- Mother cooking / travel: eat normally 1–2 days, estimate, return to prep. Does not break the phase.

### Meal pattern to log

Typical day: **desayuno → almuerzo (prep) → pre-entreno carb → cena (prep) → snack**.

Pre-WO carb ~60–80 g (plátano + toast + miel, or cooked rice + miel). Gym-day carbs sit around that pre-WO slot.

Burritos = default if adherence slips.

### Weekly weigh protocol

- Body weight **3–4 mornings/week**, fasted, same scale → 7-day average
- Optional waist 1×/week; photos every 2 weeks
- Daily mental check: hit **110 g P** and kcal **±100**
- Tripwires: weight ↓ >0.5%/week for 2 weeks → +150–200 kcal; Fase 1 weight ↑ >0.4 kg/week sustained → −150 kcal or more activity; protein <90 g several days → meat every meal (no shakes); gym strength down → check sleep + pre-WO carbs, don’t cut protein

## Training split / sessions

**PPL + PP hypertrophy.** Legs **1×/week only**. Seed **these five routines** and this calendar — not stock PPL/5×5.

**Sheet calendar (use this):**

| Day | Session |
|---|---|
| Mon | **Push A** |
| Tue | **Pull A** |
| Wed | **Legs** |
| Thu | **OFF** |
| Fri | **Push B** |
| Sat | **Pull B** |
| Sun | **OFF** |

### Global rules

- Working sets **RPE 7–9** (1–3 RIR); last set can approach RPE 9
- Compounds rest **3 min** (up to 4–5 if still gasping): presses, rows, pull-ups, squats, RDLs
- Isolation rest **60–90 s** (up to 2 min)
- Main compounds 3–4×6–10 · secondary 3×8–12 · isolation 2–3×10–15
- Overload: when **all** working sets hit the **top** of the rep range with solid form, add weight next session
- Deload every **6–8 weeks**: −40% volume, same weights, 1 week
- Warm-up: 5–10 min general + 2–3 ramp-up sets on first compound
- Abs finisher **3×/week** after Push A, Pull A, and Legs **or** Push B
- Week 1: all “~” start weights are estimates from the 100×10 bench — adjust conservatively. Legs were skipped on the cut; W1 legs are conservative, build 2–3 weeks
- Progression log in the sheet is empty — **OpenGym is the logger**

### Push A — Mon (incline + triceps/delts)

1. Incline barbell press — **4×6–10 @ 70** — PRIORITY #1
2. Flat DB / machine press — 3×8–12 @ ~30/hand
3. Seated DB shoulder press — 3×8–12 @ ~22/hand (or BB OHP ~45–50)
4. Lateral raises — 3×12–15 @ ~8/hand
5. Cable triceps pushdown — 3×10–15 @ ~25
6. OH cable / DB triceps extension — 2×10–15 @ ~12/hand DB
7. Abs: hanging knee raises + cable crunch — 2+2×10–15

### Pull A — Tue (dominadas + row + biceps)

1. Dominadas lastradas — **4×6–10 @ BW+5** — PRIORITY (BW+5–10 if strong; assisted OK; neutral or pronated)
2. Barbell / chest-supported row — 3×8–12 @ ~70 (chest-supported preferred for low back)
3. Seated cable row, neutral — 3×8–12 @ ~55
4. Rear delt fly / face pulls — 3×12–15 @ ~8/hand or ~20 cable
5. Barbell or EZ curl — 3×8–12 @ ~30
6. Incline DB curl or hammer curl — 2×10–15 @ ~10/hand
7. Abs: ab wheel / plank + dead bug — 2+2 (8–12 / 30–45 s)

### Legs — Wed (conservative W1)

1. Back squat or leg press — 3×6–10 @ ~60 squat / ~100 press
2. Lying leg curl — 3×8–12 @ ~40 (sheet: curl, not RDL as the written row)
3. Walking lunges or Bulgarian split squat — 3×8–12/leg @ ~12/hand
4. Standing or seated calf raise — 3×10–15 @ ~40
5. Leg extension optional — 2×12–15 @ ~35
6. Core: cable woodchop or Pallof — 2×10–12/side @ ~20

### Push B — Fri (arms & shoulders variant; **no front raises**)

1. Incline DB press — **4×6–10 @ ~28/hand** — PRIORITY (swap implement vs A)
2. Cable / pec deck flyes — 3×10–15 @ ~15/side
3. Lateral raises — **4×12–15** @ ~8/hand (extra volume; drop-set last set optional)
4. Machine shoulder press — 3×8–12 @ ~40
5. OH triceps extension — 3×10–15 @ ~25 cable
6. Rope pushdown + single-arm kickback — 2+2×12–15 @ ~20 / ~8

### Pull B — Sat (width + arms; **dominadas first**)

1. Dominadas / chin-ups lastradas (supinated or neutral) — **4×6–10 @ BW+5** — PRIORITY grip vs A
2. Chest-supported or wide cable row — 3×8–12 @ ~60
3. Lat pulldown — 3×8–12 @ ~50 (if pull-ups fatigued)
4. Face pulls — 3×12–15 @ ~20
5. Hammer curls — 3×10–15 @ ~12/hand
6. Preacher or concentration curl — 3×10–15 @ ~20 EZ / ~10 DB
7. Abs optional: cable crunch or hanging raises — 2×12–15 (skip if recovered elsewhere)
